# Mining the Details

This is a static blog built with Eleventy.

## Quick start

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:8081`

## Build

`npm run build`

The production output is written to `dist/`.

## Content

- New posts live in `src/posts/`
- Archive posts live in `src/archive/`
- Pages live in `src/`

Templates are in `src/_includes/`.
